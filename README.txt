BÀI THỰC HÀNH: FLEX-GROW

Tệp:
- index.html
- style.css

Cách chạy:
1. Giải nén file ZIP.
2. Mở thư mục bằng Visual Studio Code.
3. Mở index.html trong Chrome hoặc dùng Live Server.

Yêu cầu:
- Có 5 Flex Item trong cùng một vùng chứa.
- Item 2 đặt flex-grow: 1; các item còn lại flex-grow: 0.
- Quan sát Item 2 phát triển để nhận phần không gian còn trống.

Chụp ảnh:
1. Mở trang trong trình duyệt.
2. Nhấn Win + Shift + S.
3. Chọn vùng chứa tiêu đề và 5 item, lưu ảnh PNG/JPG.

Nộp GitHub:
1. Mở repository.
2. Chọn Add file -> Upload files.
3. Tải index.html và style.css lên.
4. Chọn Commit changes.
5. Sao chép link repository để dán vào CodeGym.
